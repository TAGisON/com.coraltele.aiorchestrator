Quick start — Contact Agent CC

  1. Confirm store is postgres (boot database.url).
  2. Optional: Settings — save Sarvam API key to DB (not only .env).
  3. Open Tenant Engines — PUT single listen/think/speak ids (fakes offline, or Sarvam when keyed). Never comma failover lists.
  4. Publish ≥2 Contact Agent behaviour presets (Sales + R&D / after-hours) — not the legacy failover presets.
  5. Create a Talk session; confirm gateway_binding matches tenant engines.
  6. Inject turns / language PATCH / clip match → Inspect transcript, disposition, analytics.

Legacy presets (fakes / sarvam+fake failover / captions) remain for non-CC lab work only. See docs/LAB.md.
