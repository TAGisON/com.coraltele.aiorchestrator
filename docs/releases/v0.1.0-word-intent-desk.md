# Release v0.1.0 — Word-intent Coral voice desk

**Tag:** `v0.1.0-word-intent-desk`  
**Date:** 2026-09-05  
**Branch tip:** `docs/llm-callcentre-architecture`  
**Nature:** Graph-bound **substring / word-intent** call centre (not yet LLM edge pick).

## Summary

First tagged lab release of the rebuilt LLM call-centre programme after consoles (Admin / Chat / Supervisor) and graph runtime (G.*) closed. Listen-node routing still uses **keyword/substring** edge matching. Semantic Sarvam Think edge pick is **planned** as L3 **T.0–T.5** (Doc 14) and is **not** in this runtime.

## What you get

- Production console shells: Admin (engines, profiles, bindings, flows, builder, pin), Chat (`clock=chat`), Supervisor (sessions, audit, light analytics).
- Graph brain: Entry / Speak / ListenChoice / ListenLanguage / Inform / Tool / End; repair; matrix transfer/hangup.
- Chat fix: flow dropdown loads with `tenant_id=default`.
- ListenLanguage: match on intent **or** option; BCP-47 locale from the tag field (e.g. `hindi` → `hi-IN`).
- Migration `016_drop_kb.sql`: UTF-8 BOM stripped so Postgres migrate applies cleanly.
- Lab fixture: [`tools/lab/flows/coral_inbound_triage.v2.json`](../../tools/lab/flows/coral_inbound_triage.v2.json) — Indian language picker, product FAQ path, transfers **5005 / 5006 / 5007**.

## Known limits (honest)

- Intent = **word/substring** overlap with edge labels — Hinglish/paraphrase is unreliable.
- Chat **transfer** fails without a telephony leg (`no telephony leg` / `system_failure`).
- Agent wrap-up “AI summary to human” is **out of V1**.
- Native prompt copy for every Indian locale may fall back to en-IN/hi-IN.
