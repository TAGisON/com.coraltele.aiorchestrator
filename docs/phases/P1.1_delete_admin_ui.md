## goal

Remove the desk Configurator Admin console so no implementer can “fix” or extend it.

## in_scope

- Delete `web/admin/index.html`  
- Delete `web/admin/app.js`  
- Delete empty `web/admin/` directory  

## out_scope

- `web/embed.go` / `ui.go` mounts (P1.4)  
- `web/user/**`, `web/supervisor/**`  
- New graph admin UI  
- API `/v1/desks*` (P1.6)  

## forbidden

- Porting Admin screens into a temporary page.  
- Leaving `admin/app.js` stub that calls desk APIs.  

## exit_criteria

- `web/admin/` absent.  
- `go build ./...` still succeeds (embed may fail until P1.4 if `//go:embed admin/*` remains — **if so**, P1.1 L4 must either (a) land in the same verified wave as P1.4 embed fix, or (b) temporarily adjust embed only as listed in P1.4 **without** implementing P1.2/P1.3 early). Prefer: **execute P1.1→P1.4 as four phase checks in one PR wave** if embed blocks build; still record four exit checklists.  

## edge_cases

1. Bookmark `/admin/` → after P1.4, 404; after P1.1 alone, embed may break build.  
2. `web/shared/api.js` still present until P1.4 — OK.  
3. Docs mentioning Admin URL — update only if they live under `docs/` and claim Admin is current (prefer point to 01/08).  

## verification

```text
# web/admin must not exist
go build ./...
```

## rollback

Restore `web/admin/**` from git history of pre-purge commit.
