## goal

Lock minimal slot key policy for V1 graph and whether `session_attributes` stays the store.

## in_scope

### Storage decision

**Keep** table `session_attributes`:

| Column | Decision |
|---|---|
| `session_id` | Keep FK |
| `key` | Keep |
| `value` | Keep TEXT |
| `class` | Keep — `none` \| `confidential` (masking policy) |
| `updated_at` | Keep |
| PK | `(session_id, key)` |

### V1 well-known keys (closed starter set)

| Key | class | Set by |
|---|---|---|
| `active_language` | none | ListenLanguage / Entry |
| `preferred_language` | none | Entry from caller_preference |
| `department` / intent slot | none | ListenChoice (exact key from flow node `slot.key`) |
| `ani` | confidential | Entry from caller |
| `transfer_target` | none | Tool ARM from matrix |
| `transfer_number` | confidential | Tool ARM (ops; not LLM) |

Flow-defined ListenSlot keys are allowed if they match `^[a-z][a-z0-9_]*$` and are declared on the node — not an open free-for-all from LLM.

### Policy

- LLM may propose slot **values** only when current node is ListenSlot with validation; keys never invented.  
- Tool ARM may write transfer_* from matrix only.  
- PII keys use `class=confidential`; transcript/audit must mask per policy (coding phase).  

## out_scope

- Cross-session long-term memory beyond caller_preference  
- Encrypting attribute values at rest (future)  

## forbidden

- Persisting PCM or full prompt libraries in attributes.  
- Desk-era attribute key sprawl without node declaration.  

## exit_criteria

- Table keep Locked; well-known keys + key regex Locked.  

## edge_cases

1. Session ends — rows CASCADE with session delete policy (FK today ON DELETE CASCADE).  
2. Key updates — last write wins; no history table in V1.
