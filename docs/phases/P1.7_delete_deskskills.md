Remove the Contact Desk skill gateway so ticket/email/knowledge-skill fakes cannot be mistaken for the new tool model.

## in_scope

- Delete `internal/gateway/deskskills/deskskills.go`  
- Delete `internal/gateway/deskskills/deskskills_test.go`  
- Remove directory `internal/gateway/deskskills/`  
- `cmd/aiorchestrator/main.go`: remove `deskskills` import and `deskskills.Register(reg, nil)`

## out_scope

- Renaming package to `skills` and keeping ledger behaviour.  
- Registering a “compatibility” stub gateway with the same skill names.  

## exit_criteria

- Package absent.  
- `go build ./...` green.  
- `rg "deskskills" --glob "*.go"` → zero.

2. `port.Skill` still used by other gateways — do not remove port.
