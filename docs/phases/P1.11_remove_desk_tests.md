## goal

Remove or strip tests and agent scenarios that assert Contact Desk behaviour so `go test ./...` and harness catalogs do not demand the deleted brain.

## in_scope

### Go tests

- Any remaining `*_test.go` that imports `internal/desk` or `deskskills` (should be none after P1.5–P1.7; sweep).  
- Control tests that hit `/v1/desks*` or install presets — delete those cases (e.g. remnants related to `desk_api_test.go` already deleted in P1.6).  
- `barge_policy_test.go` — already reshaped in P1.6; confirm no desk fixtures.  

### Agent harness

| Path | Action |
|---|---|
| `tests/agent/scenarios/F-live-talk-india.yaml` | **Delete** if desk/xfer-path only; else strip desk steps (prefer delete if unclean) |
| `tests/agent/scenarios/F-live-talk-cx.yaml` | Same rule |
| `tests/agent/features/catalog.yaml` | Remove desk / coral-xfer / install-desk feature entries |

Do not invent replacement graph scenarios in this phase.

## out_scope

- New validation scenarios for conversation graph  
- Edge/media unit tests that never imported desk  
- Rebuilding product-validation pipeline (after P1.9)  

## forbidden

- Keeping skipped tests (`t.Skip("desk removed")`) that still compile against desk types.  
- Soft-fail scenarios that call missing `/v1/desks` and ignore errors.  

## exit_criteria

- `go test ./...` green.  
- `rg "internal/desk|deskskills|/v1/desks|PresetCoral" tests/` → zero (or only historical comments — prefer zero).  
- Feature catalog has no desk install feature marked active.  

## edge_cases

1. Scenarios that mix media + desk — delete whole file rather than half-edit if desk is core.  
2. `tests/agent/MANIFEST.yaml` references — update if it lists deleted scenarios.  

## verification

```text
go test ./...
rg "internal/desk|deskskills|/v1/desk" tests internal --glob "*.{go,yaml,yml}"
```

## rollback
