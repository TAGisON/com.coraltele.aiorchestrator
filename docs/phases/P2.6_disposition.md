## in_scope

### Storage choice (Locked)

Keep table `session_disposition` (reuse; **no reshape DDL required for V1**):

| Column | Decision | Notes |
|---|---|---|
| `session_id` PK | Keep | FK → `session(id)` |
| `suggestion` | Keep | Optional AI/postcall guess; **not** V1 live SoT. May still hold legacy `resolved`/`unresolved`/`escalated` until ignored/backfilled |
| `template_id` | Keep | Empty OK in V1 |
| `source` | Keep | Closed vocabulary below |
| `final` | Keep | **V1 source of truth** when set — allowlisted codes only |
| `updated_at` | Keep | |

### `source` closed vocabulary (Locked)

| Value | Meaning |
|---|---|
| `live_tool` | Written after tool settle (transfer/hangup) |
| `live_graph` | Graph End without tool |
| `ops_patch` | `PATCH /v1/sessions/{id}/disposition` |
| `postcall_worker` | Async suggestion/final from postcall (default in `006`) |

### V1 `final` disposition codes (Locked)

Aligned with transfer/hangup/out-of-scope — **not** old ticket-desk list. Matches live `dispositionAllowlist` in `internal/control/disposition.go` (inventory 2026-09-04):

| Code | Meaning |
|---|---|
| `transferred_sales` | Blind transfer sales |
| `transferred_corporate` | Blind transfer corporate |
| `transferred_support` | Blind transfer support/tech |
| `transferred_other` | Transfer to matrix target not in the three above |
| `hangup_completed` | Caller/bot completed hangup tool cleanly |
| `hangup_silence` | Exhausted silence repair → hangup |
| `hangup_abuse` | Abuse path → hangup |
| `out_of_scope` | Graph End / OOD exhaust without transfer |
| `abandoned_caller` | Caller drop before terminal tool |
| `system_failure` | Orch/edge failure |

Matrix intent names map into `transferred_*` via published flow (P2.9); codes stay closed here.

### Legacy (not V1 `final`)

| Tag | Disposition |
|---|---|
| `resolved` / `unresolved` / `escalated` | **Forbidden** as the only V1 `final` set. May linger in `suggestion` or old rows — readers tolerate; new `final` writers must use allowlist above. |

### API

- `PATCH /v1/sessions/{id}/disposition`: set `final` with `source=ops_patch` only for allowlisted codes (already implemented; keep behaviour).  

### Write timing (cite 09 B4 — Locked for schema consumers)

| Event | `final` / `source` |
|---|---|
| `tool.executed` transfer | Matrix/`disposition_code` → `transferred_*`; `live_tool` |
| `tool.executed` hangup | `hangup_*`; `live_tool` |
| `tool.failed` / unknown leg | Prefer `system_failure` |
| Graph End without tool | `out_of_scope` (or graph-configured code still in allowlist); `live_graph` |
| Caller drop | `abandoned_caller` when detectable |

## edge_cases

1. Transfer executed but settle fails → prefer `system_failure` if leg state unknown (+ `tool.failed` audit per P2.4).
