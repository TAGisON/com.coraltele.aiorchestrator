## goal

Lock a **CC-oriented** closed disposition vocabulary and how it is stored for V1.

## in_scope

### Storage choice

Keep table `session_disposition` with reshape of meaning:

| Column | Decision |
|---|---|
| `session_id` PK | Keep |
| `suggestion` | **Repurpose or replace** — V1 primary field becomes `final` as source of truth when set; `suggestion` optional AI guess (postcall later). For V1 live path: write **`final`** from tool/graph End. |
| `template_id` | Keep nullable/empty — unused in V1 OK |
| `source` | Closed: `live_tool` \| `live_graph` \| `ops_patch` \| `postcall_worker` |
| `final` | Required for completed transferred/hung-up calls |
| `updated_at` | Keep |

### V1 `final` / disposition codes (closed)

Aligned with transfer/hangup/out-of-scope — **not** old ticket-desk list:

| Code | Meaning |
|---|---|
| `transferred_sales` | Blind transfer sales |
| `transferred_corporate` | Blind transfer corporate |
| `transferred_support` | Blind transfer support/tech |
| `transferred_other` | Transfer to matrix target not in the three above |
| `hangup_completed` | Caller/bot completed hangup tool cleanly |
| `hangup_silence` | Exhausted silence repair → hangup |
| `hangup_abuse` | Abuse path → hangup |
| `out_of_scope` | Graph End / OOD exhaust without transfer |
| `abandoned_caller` | Caller drop before terminal tool |
| `system_failure` | Orch/edge failure |

Matrix intent names may map into `transferred_*` via published flow (P2.9); codes stay closed here.

### API

- `PATCH /v1/sessions/{id}/disposition` (kept in P1.6 plan): may set `final` with `source=ops_patch` only for allowlisted codes.

2. Multiple patches — last `final` wins; audit via P2.4 if needed.
