## goal

Lock the explicit DROP list and **sequenced** migration order so nothing is dropped in bulk without replacement live.

## in_scope — DROP list

| Table | Why | Prerequisite |
|---|---|---|
| `desk_version` | Replaced by `flow_version` | P2.7 live; no Go readers (P1.8) |
| `desk_draft` | Replaced by `flow_draft` | same |
| `desk` | Replaced by `flow` | same |
| `kb_chunk` | OD-08-4 redesign | P2.10 `binding` live; no Go readers |
| `kb_document` | OD-08-4 | after `kb_chunk` (FK order if any) |
| `skill_invocation` | Desk skill ledger | No runtime writers; confirm unused |
| `pii_access_audit` | Desk compliance seam | Confirm unused or move — **DROP if unused** |
| `erasure_request` | Desk compliance seam | **DROP if unused** |
| `consent_record` | Desk outbound consent | **DROP if unused** in inbound V1 |

### Do **not** DROP in this phase

| Table | Reason |
|---|---|
| `session`, `audit_event`, `transcript_turn`, `session_disposition` | Reshaped, not replaced |
| `caller_preference`, `session_attributes` | Kept |
| `gateway_credentials`, `system_settings`, `tenant_engines` | Kept |
| `profile`, `profile_version` | Transition — separate OD later if profile retired |
| `playback_job`, `postcall_job` | Out of V1 focus; **defer DROP** unless proven dead (list in optional follow-up) |

## Migration sequence (one concern per file)

```text
M-A  CREATE flow, flow_draft, flow_version          (from P2.7)
M-B  CREATE binding                                  (from P2.10)
M-C  ALTER session add flow pins + recording cols    (P2.2 / P2.5)
M-D  ALTER transcript_turn expand                    (P2.3)
M-E  (readers switched — runtime phases)
M-F  DROP desk_version, desk_draft, desk             (this phase file 1)
M-G  DROP kb_chunk, kb_document                      (this phase file 2)
M-H  DROP skill_invocation, pii_access_audit,
       erasure_request, consent_record               (this phase file 3 — only after unused confirm)
```

**Forbidden:** Single migration file that CREATE flow + DROP desk + DROP kb + ALTER transcript together.

## out_scope

- Data migration desk→flow  
- Dropping `profile*`  

## forbidden

- DROP while any Go code still queries the table.  
- Editing old `008_contact_desk.sql` history.  

## exit_criteria

- DROP list Locked.  
- Sequence M-F..M-H Locked with unused-confirm checklist for compliance tables.  

## edge_cases

1. Lab DB with precious desk JSON — export manually before L4 DROP; not automated.  
2. FK from session_attributes to session — unaffected.  

## verification

`rg` Go for table names → zero before each DROP file.

## rollback

L4: restore from backup only; DROP is contract step — take DB snapshot before M-F.
