## in_scope

### Storage strategy (V1 decision)

| Choice | Decision |
|---|---|
| Registry + draft + version tables | **Yes** — mirrors publish discipline; new names |
| Normalized `flow_node` / `flow_edge` SQL rows | **No for V1** — nodes/edges live inside published **JSONB document** |
| Full JSON Schema file in repo | **Deferred** (architecture lock); this phase locks **envelope keys + enums** in prose |

Rationale: one pin per session (`flow_id`+`flow_version`); immutability of published blob; admin UI can evolve document without multi-table migrations every node edit.

### Document envelope (prose — not JSON Schema file)

Published/draft `doc` MUST be an object with at least:

| Key | Type | Meaning |
|---|---|---|
| `schema_id` | string | Constant e.g. `coral.flow.v1` — rejects desk docs |
| `entry_node_id` | string | Cursor start |
| `nodes` | array | Node objects |
| `edges` | array | Edge objects |
| `prompts` | object | `prompt_ref` → locale → text (detail P2.8) |
| `matrix` | array | Routing rows (detail P2.9) |
| `binding_refs` | array | Binding ids used by Inform/etc. (detail P2.10) |
| `globals` | array | Optional global edge ids opted in |
| `cx` | object | Optional barge/silence defaults (numbers only) |

#### Node object (required fields)

| Field | Notes |
|---|---|
| `id` | Stable within doc |
| `type` | Closed: Entry, Speak, ListenChoice, ListenLanguage, ListenSlot, Decide, Inform, Tool, End ([03](../03_BRAIN_AND_GRAPH.md)) |
| `prompt_ref` | Optional; Speak/Listen repair prompts |
| `binding_ref` | Optional; Inform |
| `tool` | Optional; Tool nodes: `transfer` \| `hangup` |
| `repair` | Optional; listen-like policies |
| `slot` | Optional; ListenSlot key + validation kind |

#### Edge object (required fields)

| Field | Notes |
|---|---|
| `id` | |
| `from` | node id |
| `to` | node id |
| `kind` | Closed: next, option, intent, retry, back, skip, repair, tool_result, global ([03](../03_BRAIN_AND_GRAPH.md)) |
| `intent` / `option` | Optional match keys |
| `matrix_intent` | Optional; Tool transfer resolves number via matrix |

### Explicit non-mapping from desk JSON

| Desk concept | Flow |
|---|---|
| `x_desk` on profile | **Gone** — session pins flow version |
| desk `steps[]` linear FSM | **Not copied** — must be redrawn as nodes/edges |
| desk skill bindings map | → `binding_refs` + P2.10 entities |
| desk matrix rows | → `matrix` / P2.9 |

**No automated desk→flow migrator in V1** unless a later OD requires it; default discard desk content at P2.13.

### Publish rules

1. Validate envelope (`schema_id`, node types, edge endpoints exist, Entry exists).  
2. Insert `flow_version` with next version; never UPDATE `doc`.  
3. Set `flow.current_version` / `status=published`.  
4. Live sessions already pinned keep old version.

## edge_cases

1. Empty matrix + Tool transfer node → publish must fail closed.  
2. Inform node without `binding_ref` → publish fail or allow only if type unused — **fail publish**.  
3. Unpublished flow → cannot pin on new live session.
