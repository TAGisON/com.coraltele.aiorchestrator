## goal

Decide keep vs reshape for credential and engine-pin tables **field-by-field**, without inventing new vendor SKUs.

## in_scope

### Existing: `gateway_credentials`

| Column | Keep? | Notes |
|---|---|---|
| `tenant_id` | Keep | PK part |
| `gateway_id` | Keep | Port/gateway id string |
| `api_key` | Keep | Secret; never log |
| `extra` JSONB | Keep | Non-secret knobs only; forbid stuffing PCM/paths of recordings |
| `updated_at` | Keep | |

**Decision:** Keep table name and shape for V1. No rename required.

### Existing: `system_settings`

| Column | Keep? | Notes |
|---|---|---|
| `tenant_id`, `key`, `value`, `updated_at` | Keep | String settings (e.g. `coral.base_url`) |

**Decision:** Keep. Document closed key prefixes later in coding principles; do not store API keys here (keys → `gateway_credentials`).

### Existing: `tenant_engines`

| Column | Keep? | Notes |
|---|---|---|
| `tenant_id` | Keep | |
| `listen_id` | Keep | STT gateway id |
| `think_id` | Keep | LLM gateway id |
| `speak_id` | Keep | TTS gateway id |
| `updated_at` | Keep | |

**Decision:** Keep for V1 Talk allowlist binding at tenant level. Per-flow overrides (if any) wait until P2.7+ and must not duplicate secrets.

### Session column `gateway_binding` (from 004)

| Decision | Keep JSONB pin on session for call-scoped gateway override; P2.2 records it in session field table. |
