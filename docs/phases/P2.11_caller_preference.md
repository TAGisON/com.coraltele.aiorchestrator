## in_scope

### Table `caller_preference` — keep

| Column | Decision |
|---|---|
| `tenant_id` | Keep — PK part |
| `ani` | Keep — normalised digits policy at runtime (E.164 or national digits — coding phase) |

**Decision:** No rename. No extra columns for V1.

### Runtime rules (bind later)

1. Entry may read preference into slot `preferred_language` / seed `active_language` only if in allowlist.  
2. ListenLanguage success **writes** preference (`source=user_said`).  
3. Weak greetings must not lock language ([02](../02_CURRENT_STATE.md) lesson) — behaviour owned by graph/turn machine, not this table.
