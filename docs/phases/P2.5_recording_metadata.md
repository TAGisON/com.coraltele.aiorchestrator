## goal

Lock how recording is **referenced and lifecycle-stamped** in DB, and the behavioural rule that stop is mandatory on Ending — without putting PCM in Postgres.

## in_scope

### Storage choice (Locked)

**V1:** Keep `session.recording_ref` as the pointer; **add** lifecycle columns on `session` (expand). Separate `recording` table **rejected** for V1 (fewer joins).

### Current vs add (inventory)

| Column | Today | Decision |
|---|---|---|
| `recording_ref` | Present (`001` TEXT) | **Keep** — opaque ref / relative path id (today: on-disk path from `record.Recorder.Path`) |
| `recording_started_at` | Absent | **Add** TIMESTAMPTZ NULL |
| `recording_stopped_at` | Absent | **Add** TIMESTAMPTZ NULL |
| `recording_stop_reason` | Absent | **Add** TEXT NOT NULL DEFAULT '' |
| `recording_bytes` | Absent | **Add** BIGINT NULL — optional size after stop |

### `recording_stop_reason` closed vocabulary (Locked)

| Value | Meaning |
|---|---|
| `` (empty) | Not stopped yet / never started |
| `session_ending` | Stop requested on Ending / `Draining` |
| `session_completed` | Stopped on `Completed` path |
| `session_cancelled` | Stopped on `Cancelled` path |
| `session_failed` | Stopped on `Failed` path |
| `orphan_reaper` | Ops/reaper closed leaked recorder (`started_at` set, `stopped_at` null after terminal) |
| `manual` | Explicit ops stop |

(`session_cancelled` added to align with P2.2 state allowlist.)

### Behavioural rules (bind runtime later — E.2; schema supports them)

1. On transition to Ending (`Draining`): **must** request stop; await close; set `recording_stopped_at` + reason.  
2. WebSocket teardown must not skip stop ([04](../04_LIVE_TURN_MACHINE.md), [02](../02_CURRENT_STATE.md) leak lesson).  
3. If process crash: reaper uses `recording_started_at IS NOT NULL AND recording_stopped_at IS NULL` after session terminal → stamp `orphan_reaper`.  
4. PCM only on filesystem/object store keyed by `recording_ref` — never BYTEA.  
5. Start policy V1: ASAP after answer / media ready ([09](../09_EVIDENCE_AND_RECORDING.md) B3); exact hook = runtime E.2.  
6. Audit: emit `recording.started` / `recording.stopped` per P2.4 when writers exist.

## edge_cases

1. Transfer: recording policy = stop with orch leg end (V1); post-transfer human leg not orch’s recording unless later OD.  
2. Hangup before any start — `recording_ref` null/empty and timestamps null OK (EC-04 spirit).  
3. Start fails — call may continue; empty ref; no crash loop ([10](../10_CODING_PRINCIPLES.md) EC-04).
