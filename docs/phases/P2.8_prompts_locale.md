## goal

Lock how `prompt_ref` resolves to per-locale text for a published flow version.

## in_scope

### V1 storage decision (Locked)

**Embedded** in `flow_draft.doc` / `flow_version.doc` under key `prompts` (no separate SQL table for V1):

```text
prompts: {
  "<prompt_ref>": {
    "<locale>": "<text>",
    ...
  },
  ...
}
```

### Envelope addition (Locked — extends P2.7)

| Key | Type | Meaning |
|---|---|---|
| `default_locale` | string | Required at publish — BCP-47 Talk locale used when fallback reaches default |
| `prompts` | object | Map as above; required object (may be empty only if no Speak/repair refs — publish should fail if any `prompt_ref` lacks text for `default_locale`) |

### Rules (Locked)

| Rule | Detail |
|---|---|
| Locale keys | BCP-47 style used by Talk allowlist (e.g. `en-IN`, `hi-IN`) |
| Resolve order at runtime | `active_language` → `default_locale` → **fail closed** (no silent invent of English or other locale) |
| Versioning | Immutable with `flow_version`; edit only via draft → new publish |
| Separate `flow_prompt` table | **Not V1** — revisit if admin UX needs SQL search |
| Node shape | Nodes carry single `prompt_ref` string; **not** inline multi-locale blobs |

### Reserved / conventional `prompt_ref` examples (not exhaustive product copy)

| Ref | Typical use |
|---|---|
| `welcome` | Entry/Speak welcome |
| `closing_transfer` | Tool transfer closing |
| `closing_hangup` | Tool hangup closing |
| `repair_unclear` | Listen repair |
| `silence_nudge_1` | Silence policy |

Publish validation (cite with P2.7 rules): every `prompt_ref` referenced by a node must exist under `prompts` with at least `default_locale` text.

- Updating `flow_version.doc.prompts` in place.  
- PCM / audio blobs in `prompts` values.  
- Free LLM rewrite of published prompt text at runtime.

## migration_plan_note

**None.** Prompt storage is JSON inside `flow_draft` / `flow_version` created under P2.7 DDL wave. No additive prompt-only migration.

## edge_cases

1. Locale in allowlist but missing prompt text → fail closed for that Speak (after fallback exhausted).  
2. Mid-call language switch → subsequent prompts use new `active_language`.  
3. `default_locale` not in Talk allowlist → publish fail closed.
