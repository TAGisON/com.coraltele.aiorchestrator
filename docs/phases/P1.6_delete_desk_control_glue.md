## edge_cases

1. Published profiles with `x_desk` — ignore; do not crash on answer.  
2. In-flight lab calls mid-purge — out of scope; restart orch after deploy.  
3. `EndSessionFromDesk` was session-end hook — replace with neutral session end if still required by runtime, **without** desk disposition logic invention beyond “stop session.”  
4. Barge-in without desk CX — use documented default (e.g. prior `DefaultCX` numeric defaults copied once into `barge_policy.go` comments citing “former desk DefaultCX; not imported”).  
5. Transfer/hangup from old desk paths gone — edge transfer API may remain for manual/lab callops.
