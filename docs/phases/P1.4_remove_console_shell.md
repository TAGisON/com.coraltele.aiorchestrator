## goal

Stop shipping the three-console product shell so the process no longer embeds or mounts Admin/User/Supervisor.

## in_scope

- Rewrite `web/embed.go` so `//go:embed` does **not** reference `admin/*`, `supervisor/*`, `user/*` (and drop `shared/*` if unused).  
- Remove or replace `web/index.html` three-console chooser.  
- Update `internal/control/ui.go` `mountUIRoutes`: remove `mountStatic` for `/admin`, `/user`, `/supervisor`, `/shared`.  
- Decide `GET /` behaviour: minimal placeholder **or** 404 — must **not** link to old consoles.  
- Delete `web/shared/styles.css`, `web/shared/api.js` if nothing else embeds them.  

## out_scope

- New Admin/graph editor UI  
- Removing JSON APIs under `/v1/profiles`, `/v1/sessions`, `/v1/platform/status` (those handlers in `ui.go` may remain)  
- Desk API removal (P1.6)  

## forbidden

- Replacing shell with a fourth “temporary lab UI” that edits desks.  
- Keeping embed of empty admin dirs.  

## exit_criteria

- `go build ./...` green.  
- No static file service for `/admin`, `/user`, `/supervisor`.  
- `GET /` does not present three-console navigation.  
- `web/embed.go` matches remaining files only.  

## edge_cases

1. `main.go` still passes `web.UIFS` into control — must compile with new embed set.  
2. External monitors hitting `/` — document new response body/status in phase notes when L4 runs.  
3. If P1.1–P1.3 deleted files first without this phase, build breaks until embed updated — **expected**; finish P1.4 before declaring wave green.  

## verification

```text
go build ./...
# curl or browser: /admin /user /supervisor → not served as old SPAs
# curl / → no console chooser links to admin/user/supervisor
```

## rollback

Restore `web/embed.go`, `web/index.html`, `web/shared/**`, and `ui.go` mountStatic block from git.
