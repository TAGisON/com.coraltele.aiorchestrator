## goal

Keep `audit_event` table shape; lock V1 **emitter** `event_type` vocabulary and payload rules.

## in_scope

### Table columns — keep

| Column | Decision |
|---|---|
| `id` BIGSERIAL | Keep |
| `session_id` | Keep (nullable only for non-session platform events if any; prefer always set for call audits) |
| `tenant_id` | Keep |
| `event_type` | Keep — closed emitter list below |
| `payload` JSONB | Keep — no secrets, no PCM |
| `created_at` | Keep — append-only |

No column rename required for V1.

### V1 `event_type` allowlist (emitters)

| event_type | When |
|---|---|
| `session.created` | Session row created |
| `session.live` | Entered live media |
| `session.ending` | Ending started |
| `session.completed` | Terminal clean |
| `session.failed` | Terminal failure |
| `turn.state` | Optional: turn machine state change (`from`,`to`) |
| `stt.final` | Optional duplicate of transcript; prefer transcript table as SoT — emit only if ops need audit mirror |
| `graph.edge` | Edge selected (`edge_id`,`node_from`,`node_to`) |
| `tool.armed` | Tool lock; params frozen (numbers from matrix — OK in payload) |
| `tool.executing` | Edge verb sent |
| `tool.executed` | Settle OK |
| `tool.failed` | Settle/send failure |
| `recording.started` | Recorder started |
| `recording.stopped` | Stopped with reason |
| `language.changed` | Active language change |

**Deprecated (do not emit after P1.12):** `desk.end`, `desk.transfer`, any `desk.*`.

### Payload rules

- No `api_key`, tokens, raw PCM, full WAV paths beyond `recording_ref` id.  
- Tool params may include destination number (operational need) — still not LLM-invented at write time.

## out_scope

- Analytics warehouse export  
- Rewriting historical `desk.*` rows  

## forbidden

- Open-ended `event_type` from LLM text.  
- UPDATE of existing audit rows.  

## exit_criteria

- Allowlist Locked.  
- DDL: **none** unless adding index `(session_id, event_type)` — optional note.  

## edge_cases

1. Old rows with unknown types — readers must tolerate.  
2. Duplicate `tool.armed` — should not happen; if retry, new event with failure reason on prior.  

## verification

Grep current emitters before L4; align code to allowlist in a later runtime phase citing this doc.
