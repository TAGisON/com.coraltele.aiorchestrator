## goal

Evolve storage from turn-pair rows to **event-capable** transcript aligned with actionable vs transcript-only STT.

## in_scope

### Option chosen (Locked)

**Keep physical table name `transcript_turn`** for V1 (widen meaning to events). Conceptual docs may say transcript event; no rename migration in V1 unless a later OD forces it.

### Current columns → decision (inventory)

| Column (today / Go) | Decision | Notes |
|---|---|---|
| `id` BIGSERIAL | Keep | PK |
| `session_id` | Keep | FK → `session(id)` |
| `seq` INT | Keep | Strict append order per session; UNIQUE with session |
| `role` TEXT | Keep | Closed: `user` \| `assistant` \| `system` (Go today). Allow **`tool`** when emitters need tool lines — closed four-value set for V1 emitters |
| `text` TEXT | Keep | May be empty only when `event_kind` is a non-text marker |
| `turn_id` TEXT | **Reshape** | Today NOT NULL + UNIQUE(session, turn_id, role) assumes pairs. Locked: drop pair unique; `turn_id` becomes **nullable** correlation id (omit when N/A) |
| `created_at` | Keep | TIMESTAMPTZ; set once (P2.0-P2 / P4) |

### Add columns (expand — one future migration concern)

| Column | Type | Meaning |
|---|---|---|
| `event_kind` | TEXT NOT NULL DEFAULT `'utterance'` | Closed set below; backfill maps legacy rows |
| `actionable` | BOOLEAN NULL | User STT finals: true/false; NULL if N/A |
| `actionable_reason` | TEXT NOT NULL DEFAULT '' | Why transcript-only (echo, tool_lock, too_short, legacy_import, …) |
| `node_id` | TEXT NOT NULL DEFAULT '' | Graph cursor if known |
| `edge_id` | TEXT NOT NULL DEFAULT '' | Edge taken if any |
| `language` | TEXT NOT NULL DEFAULT '' | Language of this utterance if known |
| `payload` | JSONB NOT NULL DEFAULT '{}' | Small structured extras; **no PCM** |

Default `'utterance'` is a migrate placeholder only; backfill must set real kinds per mapping table (do not leave production rows on placeholder if avoidable — prefer backfill in same migration concern).

### `event_kind` closed vocabulary (V1 Locked)

| Kind | Role typical | Notes |
|---|---|---|
| `bot_speak_start` | assistant/system | Optional; min V1 may omit |
| `bot_speak_end` | assistant/system | Optional |
| `bot_utterance` | assistant | TTS text committed |
| `user_final` | user | STT final; set `actionable` / `actionable_reason` |
| `edge_taken` | system | Graph moved |
| `tool_line` | assistant/system/tool | Closing line associated with tool |
| `note` | system | Freeform system note |
| `utterance` | *legacy placeholder* | Only for pre-backfill rows; emitters must not write new `utterance` after cutover |

**V1 minimum emitters (later runtime / E.\*):** `bot_utterance`, `user_final`, `edge_taken`, `tool_line`.

### Mapping from old rows

| Old row | New |
|---|---|
| role=user, text set | `event_kind=user_final`, `actionable=true`, `actionable_reason='legacy_import'` |
| role=assistant | `event_kind=bot_utterance` |
| role=system | `event_kind=note` |

### Unique constraint change plan (Locked)

| Step | Action |
|---|---|
| 1 | ADD new columns with defaults (expand) |
| 2 | Backfill `event_kind` / actionable per mapping |
| 3 | DROP CONSTRAINT `UNIQUE (session_id, turn_id, role)` |
| 4 | ALTER `turn_id` → NULL allowed |
| 5 | KEEP `UNIQUE (session_id, seq)` |

**One migration concern** (single new file when authored later) — do not bundle with desk DROP or flow create (P2.0-P10). **No SQL authored in this P2.3 L4 lock.**
