## goal

Evolve storage from turn-pair rows to **event-capable** transcript aligned with actionable vs transcript-only STT.

## in_scope

### Option chosen (planning)

**Expand `transcript_turn` (or rename conceptually to transcript_event in docs; physical rename optional later)** via expand/contract:

Keep table name `transcript_turn` for V1 migrations to reduce blast radius **unless** rename is cheap post-P1 — prefer **keep name**, widen meaning.

### Columns

| Column | Decision |
|---|---|
| `id` BIGSERIAL | Keep |
| `session_id` | Keep FK |
| `seq` INT | Keep — strict append order per session |
| `role` TEXT | Keep; closed: `user` \| `assistant` \| `system` \| add `tool` if needed for tool lines |
| `text` TEXT | Keep; may be empty for non-text markers only if `event_kind` explains |
| `turn_id` TEXT | **Relax uniqueness** — today UNIQUE(session, turn_id, role) assumes pairs; continuous events may share or omit. P2.3 locks: `turn_id` nullable or correlation id without unique pair assumption |
| `created_at` | Keep |

### Add columns

| Column | Type | Meaning |
|---|---|---|
| `event_kind` | TEXT NOT NULL DEFAULT `'utterance'` | Closed set below |
| `actionable` | BOOLEAN NULL | For user STT finals: true/false; NULL if N/A |
| `actionable_reason` | TEXT NOT NULL DEFAULT '' | Why transcript-only (echo, tool_lock, too_short, …) |
| `node_id` | TEXT NOT NULL DEFAULT '' | Graph cursor if known |
| `edge_id` | TEXT NOT NULL DEFAULT '' | Edge taken if any |
| `language` | TEXT NOT NULL DEFAULT '' | Language of this utterance if known |
| `payload` | JSONB NOT NULL DEFAULT '{}' | Small structured extras; **no PCM** |

### `event_kind` closed vocabulary (V1)

| Kind | Role typical | Notes |
|---|---|---|
| `bot_speak_start` | assistant/system | Optional if noisy; min V1 may omit start/end and only store spoken text |
| `bot_speak_end` | assistant/system | Optional |
| `bot_utterance` | assistant | TTS text committed |
| `user_final` | user | STT final; set actionable* |
| `edge_taken` | system | Graph moved |
| `tool_line` | assistant/system | Closing line associated with tool |
| `note` | system | Freeform system note |

**V1 minimum to implement later:** `bot_utterance`, `user_final`, `edge_taken`, `tool_line`. Start/end optional.

### Mapping from old rows

| Old row | New |
|---|---|
| role=user, text set | `event_kind=user_final`, `actionable=true` (unknown history — default true with reason `legacy_import`) |
| role=assistant | `event_kind=bot_utterance` |
| role=system | `event_kind=note` |

## out_scope

- Runtime emitter implementation  
- Full doc 09 product UX for transcript viewer  
- Storing audio offsets (may add later)  

## forbidden

- Deleting suppressed/transcript-only user finals.  
- Overwriting `text` in place for “cleanup.”  
- PCM in `payload`.  

## exit_criteria

- Column + vocabulary tables Locked.  
- Unique constraint change plan written (drop pair unique; keep `(session_id, seq)` unique).  
- Migration = expand columns + constraint change; backfill defaults — **one concern**.  

## edge_cases

1. Barge overlap order — `seq` / `created_at` is orch truth; offline WAV STT may disagree ([02](../02_CURRENT_STATE.md)).  
2. Empty actionable_reason when actionable=true — OK.
